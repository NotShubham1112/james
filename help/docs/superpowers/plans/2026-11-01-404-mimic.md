> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the study resources page with a minimal "404 Not Found" page that downloads a text file when clicking "again".

**Architecture:** 
A single Next.js page (`app/page.tsx`) using Tailwind CSS for layout. A static text file (`public/experiments.txt`) is served for download via a standard anchor tag.

**Tech Stack:** Next.js, Tailwind CSS.

## Global Constraints
- Theme: White background, black text.
- Layout: Minimal design, centered content.
- Asset: `public/experiments.txt` must exist.
